# Code for: Gut microbiome cancer tests over-flag people with chronic disease, and routine colonoscopy outcomes can keep their false alarms on target

## Layout
- `src/` - data loading (`data.py`), fixed classifiers (`models.py`), threshold rules incl. the proposed
  `SequentialRecalibrator` (verified-positive recalibration with drift alarm) (`calibrate.py`).
- `experiments/data_lock.md` - cohort roles fixed before method development.
- `experiments/development_log.md` - every idea tried on development data, including failures (rounds 1-9).
- `experiments/protocol.md` - frozen analysis protocol; `protocol_freeze_hashes.txt` - SHA-256 of the frozen files.
- `experiments/dev/` - development scripts (development cohorts only) and their logs.
- `experiments/final/run_final.py` - locked analysis (refuses to run unless the protocol is frozen);
  `analyze_final.py` - endpoints and tests; `RESULTS_locked.md` and `results/` - outputs.
  (`results/sequential.csv.gz`, 64 MB, and `partC_groupcal.csv.gz` are regenerated by `run_final.py`.)
- `figures/` - main figures and Supporting Information tables.
- `pilot/` - motivating pilot analysis.
- `experiments/protocol_addendum_drugs.md` - second pre-specified protocol (medications), committed before analysis;
  `addendum_drugs.py` (dev | confirm), `addendum_metformin_explore.py` (exploratory), `addendum_results/`.
- `cutoffguard/` - installable Python package of the proposed rule (`pip install ./cutoffguard`; tests: `pytest cutoffguard/tests`).

## Reproduce
```
pip install -r requirements.txt
mkdir data_cache && cd data_cache
curl -L -o eh.sqlite3 https://experimenthub.bioconductor.org/metadata/experimenthub.sqlite3
# sample metadata (curatedMetagenomicData package data, devel branch)
curl -L -o sm.rda https://raw.githubusercontent.com/waldronlab/curatedMetagenomicData/devel/data/sampleMetadata.rda
python3 -c "import pyreadr; list(pyreadr.read_r('sm.rda').values())[0].to_csv('sampleMetadata.csv', index=False)"
python3 ../scripts/fetch_cmd.py FengQ_2015,GuptaA_2019,HanniganGD_2017,ThomasAM_2018a,ThomasAM_2018b,ThomasAM_2019_c,VogtmannE_2016,WirbelJ_2018,YachidaS_2019,YuJ_2015,ZellerG_2014,HMP_2019_ibdmdb,HallAB_2017,IjazUZ_2017,NielsenHB_2014,KarlssonFH_2013,QinJ_2012,SankaranarayananK_2015,JieZ_2017,QinN_2014,LiJ_2017,ChengpingW_2017,ZhuF_2020,LoombaR_2017,LiJ_2014,VilaAV_2018,HMP_2019_t2d,NagySzakalD_2017,XieH_2016
python3 ../scripts/fetch_cmd.py 2022-10-19.MetaCardis_2020_a.relative_abundance
python3 ../scripts/fetch_cmd.py VincentC_2016 && python3 ../scripts/fetch_cmd.py 2022-04-13.LeeKA_2022.relative_abundance
cd ..
export CMD_CACHE=$PWD/data_cache
python3 experiments/final/run_final.py      # ~45 min on 4 CPU cores
python3 experiments/final/analyze_final.py results
python3 experiments/addendum_drugs.py dev && python3 experiments/addendum_drugs.py confirm
python3 experiments/addendum_metformin_explore.py
python3 figures/make_figures.py && python3 figures/make_si_tables.py && python3 figures/make_graphical_abstract.py
```
Set `CMD_CACHE` to the data cache directory (default: `../../../data_cache` relative to `src/`).
