# Before you submit to iMeta - fill these in

Placeholders in Manuscript.docx / Cover_Letter.docx (search for "[" ):
- [ ] [Second Author] name (supervisor, corresponding author) - title page, author contributions, cover letter
- [ ] [corresponding author email]
- [ ] [ORCID] for both authors
- [ ] [GitHub repository URL] in the Data Availability Statement - upload the `code/` folder to a public repository
      (optionally archive it on Zenodo for a DOI)
- [ ] [Date] on the cover letter

Checks the authors must do themselves:
- [ ] Read the full manuscript and Supporting Information; confirm every number against `code/experiments/final/RESULTS_locked.md`.
- [ ] Confirm iMeta's current author guidelines on the journal site (word limit, reference style, graphical abstract,
      figure format); the guideline page could not be opened from our environment.
- [ ] Confirm iMeta's impact factor/quartile in Clarivate JCR if your institution requires it (secondary sources: Q1).
- [ ] Keep the AI-assisted technologies declaration - Wiley/iMeta require disclosure of AI use; removing it risks
      rejection or retraction.
- [ ] Prepare a graphical abstract image (iMeta requires one; the 100-word summary is in the manuscript).
- [ ] Both authors approve the final version.

Package contents:
- Manuscript.docx (main text, figure legends, references; figures embedded at the end for review)
- Supporting_Information.docx (Methods S1-S7, Tables S1-S5)
- Cover_Letter.docx
- figures/Figure1.pdf, Figure2.pdf (vector) + PNG previews
- code/ (all analysis code, frozen protocol, development log, locked results)
